# Interactive Science Comic: Light and Sound

## Project Overview

Interactive Science Comic is a digital learning application designed for Grade 5 elementary school students. It presents science learning materials about Light and Sound through an engaging comic-based learning experience.

The application combines educational storytelling, interactive questions, and audio elements to create a more engaging and participatory learning environment.

## Project Objectives

- Present science concepts through an accessible digital comic format.
- Encourage students to actively participate in the learning process.
- Provide interactive questions to support student understanding.
- Create an engaging learning experience through visual and audio elements.

## Tools & Technologies

- GDevelop 5
- Visual Event-Based Programming
- Digital Illustration and Audio Integration

## Key Features

### 1. Digital Comic-Based Learning
Learning materials about Light and Sound are presented through comic-style visual storytelling.

### 2. Interactive Multiple-Choice Questions
Students can select answers directly within the application.

### 3. Dynamic Application Responses
The application responds according to the options selected by students, creating an interactive learning experience.

### 4. Audio Integration
Sound effects and audio elements are incorporated to support the learning experience.

## Development Concepts

- Event-based programming
- User interaction and input handling
- Conditional logic
- Interactive navigation
- Audio integration
- Educational game development

## My Role

Designed and developed the interactive learning application using GDevelop 5, combining educational content, visual storytelling, interactive answer choices, and audio elements.

## Learning Outcomes

Through this project, I explored how game development tools can be applied to educational environments. I gained experience in designing interactive learning experiences, implementing event-based logic, and integrating multimedia elements into digital educational content.
